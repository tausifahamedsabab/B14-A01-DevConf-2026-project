A sleek, fully responsive landing page built for **DevConf 2026**, a premier developer conference. The page highlights featured speakers, ticket pricing tiers, and a hackathon competition section — all wrapped in a clean, modern UI.

## ✨ Key Features

- 🎯 **Hero Section** — Eye-catching banner with call-to-action
- 🧑‍💻 **Speakers Section** — Grid showcasing featured speakers with tags and titles
- 💳 **Pricing Section** — Three-tier pricing cards (Standard, Pro, Team) with feature comparisons
- 🏆 **Hackathon Section** — Competition tracks with prize pools and a waitlist call-to-action
- 📱 **Fully Responsive Layout** — Built with Flexbox and CSS Grid for adaptability across devices
- 🎨 **Custom Hover Effects** — Interactive buttons with smooth hover transitions
- 🦶 **Footer** — Social links and policy navigation

## 🚀 Getting Started (Run Locally)

Follow these steps to run the project on your local machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/devconf.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd devconf
   ```

3. **Open the project**

   Simply open `index.html` in your browser, or use the **Live Server** extension in VS Code for auto-reload:
   - Right-click `index.html` → **"Open with Live Server"**

   No build tools, installations, or dependencies needed! ✅
